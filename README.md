
# An-Archive (AnA의 스토리지 시스템; 백엔드)
> An-Archive(언-아카이브)는 선린인터넷고등학교 소프트웨어과 서버개발동아리인 AnA 제작한 스토리지 시스템이에요.

> [!CAUTION]
> 해당 프로젝트는 아직 개발 초기 단계에 있어요.

## Roadmap
- [x] 프로젝트 초기 설정
- [x] Docker 컨테이너화
- [ ] An-Americano Golang Wrapper를 활용한 사용자 인증 및 권한 관리 시스템 구축
- [ ] 파일 업로드 및 다운로드 기능 구현
- [ ] S3 호환 API 구축
- [ ] API 문서화 및 테스트 작성
- [ ] 성능 최적화 및 보안 강화

## Tech Stack
- [Spine](https://github.com/NARUBROWN/spine)
- [Bun](https://github.com/uptrace/bun)
- [An-Americano Golang Wrapper](https://github.com/sunrin-ana/anamericano-golang)
- PostgreSQL
- Docker
